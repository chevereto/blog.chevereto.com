Chevereto Cloud Preview

Now open for public test preview

Rodolfo Berrios   Rodolfo

We're excited to announce that Chevereto Cloud is now live and open for test preview at cloudpreview.chevereto.com.

Chevereto Cloud is our fully managed hosting service. All the power of Chevereto with none of the server work. No setup, no maintenance, no licensing fees. Your platform, running in seconds.

# What makes it different

Chevereto Cloud was built around the same principles that define the software itself: your data is yours, always.

  • BYOS: Bring Your Own Storage: Connect AWS S3, Cloudflare R2, Backblaze B2, Google Cloud, Azure, Wasabi, and more. Your files never touch our servers.
  • True data ownership: We claim no rights or licenses over your content. Ever.
  • No vendor lock-in: Switch to self-hosted at any time. Your data, your call.
  • Everything included: Accounts, 2FA, albums, admin dashboard, multi-storage, themes, API, custom branding. No tracking, no ads.

# Test preview details

This is a test preview. All data will be reset when the preview period ends, so don't use it for anything you intend to keep. There's no checkout involved, sign up and explore freely.

Read the full announcement in the community forum: 🎉 Introducing Chevereto Cloud (Test Preview).

# Try it now

Go to cloudpreview.chevereto.com, sign up, and start testing. This preview exists to get real feedback from real users. If you find something that doesn't work the way it should, we want to hear about it.
